이메일 로그인 후 기존 기록을 대조하고, 안전 확인을 거쳐 자동 동기화를 시작합니다. 사진은 아래 별도 버튼으로 동기화합니다.

자동 동기화 꺼짐 · 시작 버튼을 누르면 로컬 기록과 클라우드 기록을 먼저 대조합니다.

마지막 동기화 성공: 아직 없음

기본은 수동 방식입니다. 위 체크박스를 선택하면 로그인 세션을 이 브라우저에 보관하고 재접속 시 안전 비교 후 자동으로 시작합니다. 공용 PC에서는 선택하지 마세요. 로그아웃하면 저장된 세션도 삭제합니다. 기록이 다르면 시작하지 않습니다. 자동 동기화 시작 후 로컬 변경은 클라우드에 저장하고, 다른 기기의 변경은 이 브라우저에 미수정 사항이 있을 때만 자동으로 가져옵니다. 양쪽이 모두 변경됐다면 자동 중지합니다. 자동 다운로드 후 화면을 새로고침하며 자동 동기화는 다시 시작해야 합니다. 업로드는 클라우드의 이전 기록을 교체하며, 다운로드는 이 브라우저의 일정·관심 공연·공연장 목록을 교체합니다. 수동 기록 업로드·다운로드는 사진을 변경하지 않습니다. 작업 전 「백업 파일 다운로드」를 권장합니다.

프로젝트 URL은 Settings → Data API의 URL, 공개 키는 Settings → API Keys의 Publishable Key를 입력하세요. service_role 또는 secret 키는 절대 입력하지 마세요. 이메일 가입 시 Supabase 설정에 따라 인증 메일 확인이 필요할 수 있습니다. 비밀번호는 브라우저 저장소에 보관하지 않습니다. 로그인 세션은 이 탭에서만 유지됩니다.
